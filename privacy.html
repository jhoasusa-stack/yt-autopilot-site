Privacy Policy

Last updated: September 20, 2026

yt-autopilot is a private, single-user publishing tool. It is operated by one person, the owner of the YouTube channel “El Precio de No Saber”, to manage YouTube channels that he owns. It is not offered to the public and has no other users.

1. YouTube API Services

yt-autopilot uses YouTube API Services. By using the tool, its operator agrees to be bound by the YouTube Terms of Service. Data handled through YouTube API Services is also subject to the Google Privacy Policy.

2. What data the tool accesses

After the channel owner signs in with Google and grants consent, the tool accesses only data from the owner’s own YouTube channels:

  • Channel information (channel ID, title, subscriber count) to confirm the correct channel is connected.
  • The owner’s own videos and their metadata, in order to upload videos, set titles, descriptions, tags, thumbnails and scheduled publish times.
  • YouTube Analytics reports for the owner’s own channels (views, watch time, click-through rate, retention), in order to decide future topics.

The tool does not access, collect or store data about any other YouTube user, viewer or commenter.

3. How the data is used

The data is used only to publish the owner’s videos to the owner’s channels and to show the owner statistics about those channels. It is never sold, rented, shared with or transferred to third parties, and it is never used for advertising or profiling.

4. Where the data is stored

All data, including the OAuth authorization tokens, is stored locally on the owner’s personal computer. Nothing is uploaded to any server operated by yt-autopilot, because there is none. Analytics data retrieved through the API is refreshed at least every 30 days or deleted.

5. Cookies and tracking

yt-autopilot is a command-line program. It does not use cookies, does not place or read information on any visitor’s device, and this website contains no analytics or tracking scripts.

6. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the tool can no longer reach the channel. Locally stored data can be deleted by removing the tool’s data folder; a deletion request can also be sent to the contact address below and will be completed within 7 days.

7. Contact

Questions about this policy: elpreciodenosaber@gmail.com
